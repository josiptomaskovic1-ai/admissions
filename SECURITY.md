# Security policy

## Supported version

Only the current production version of Adria Admissions is supported.

## Reporting a vulnerability

Please report suspected security issues privately to
[adria.admissions@gmail.com](mailto:adria.admissions@gmail.com).

Include the affected URL, a clear description, reproduction steps, and the
potential impact. Do not include real applicant data and do not publish the
issue before we have had a reasonable opportunity to investigate it.

We will acknowledge a complete report as soon as practical, assess its impact,
and coordinate remediation and disclosure with the reporter.
